Conferir no site do Ninite

  1. Toque em Baixar instalador. O arquivo ninite.exe vem do site do Ninite.
  2. Abra o arquivo baixado. Se o Windows pedir permissão, escolha Sim.
  3. Espere. O Ninite baixa e instala tudo sozinho, e fecha quando termina.
  4. Para atualizar tudo depois, abra o mesmo ninite.exe de novo.
Antes de instalar
  • Só funciona no Windows. Não serve para Mac, Linux, celular ou tablet.
  • Baixe somente em ninite.com. Não use sites que oferecem o mesmo arquivo.
  • Em computadores do laboratório ou da escola, peça permissão antes. Pode ser que a instalação esteja bloqueada.
  • O Ninite é gratuito para uso pessoal e instala as versões originais dos programas, sem barras de ferramentas.
  • O Windows já traz o Microsoft Defender. Não precisa instalar outro antivírus.
